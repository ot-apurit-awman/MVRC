# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately by contacting the repository
owner, [@ot-apurit-awman](https://github.com/ot-apurit-awman), through GitHub. Do not open a
public issue for an undisclosed vulnerability.

Include the affected version, a clear description of the issue, reproduction
steps, and any relevant logs or proof of concept. Remove personal paths,
tokens, and other private information from attachments.

## Scope

This policy covers MVRC source code and release workflows. My Winter Car,
Unity, PlayMaker, MSCLoader, OpenVR, and other third-party components remain
subject to their respective owners' security policies.
